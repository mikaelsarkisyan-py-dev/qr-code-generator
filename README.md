# QR Code Generator and Reader

A desktop app, written in Python, that generates QR codes and reads them back. It was built as a team project during my BSc Computer Science.

## Features

- **Generate QR codes** (versions 1 and 2, byte mode) with automatic or manual choice of version and error correction level (L, M, Q, H)
- **Automatic mask selection** by scoring all eight mask patterns against the four standard penalty rules
- **Read QR codes** from image files, including decoding the format information (BCH) and Reed-Solomon error correction
- **Accessibility presets**: standard, high contrast for low vision, and colour-blind friendly, plus a custom colour picker
- **Contrast warnings**: the app calculates the contrast ratio between your chosen colours (using the WCAG luminance formula) and warns if the code may be hard to scan
- **Analytics tab** that logs each generation attempt and charts error correction usage and success against failure over time

## How it works

Text is encoded to a bitstream (mode indicator, length, data, terminator and padding). Reed-Solomon error correction bytes are added using the `reedsolo` library. The bits are placed into a matrix alongside the finder, alignment and timing patterns. The format information is encoded with a BCH code. The reader reverses this process.

## Limitations

- QR versions 1 and 2 only, and byte mode only (ISO-8859-1 text, up to 32 characters)
- The reader works best on codes generated by this app

## Running it

Requires Python 3.11.

```
git clone https://github.com/mikaelsarkisyan-py-dev/qr-code-generator.git
cd qr-code-generator
pip install -r requirements.txt
cd qr_app
python qr_main.py
```

The first launch shows a short licence agreement. Generated codes are saved to a `generated_codes` folder.
